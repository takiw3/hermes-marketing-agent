# Examples

Worked examples of the shapes this profile uses in practice: an incoming
Kanban task brief, its matching result handoff, a first direct-chat
conversation, and a finished deliverable.

Three things to know before reading or copying them:

- **Everything here is synthetic.** Kettle & Crate, Ledgerline Bookkeeping,
  their owners, URLs, prices, and list sizes are all fictional and are not
  based on any real business or person. The `.example` domains do not
  resolve anywhere.
- **Repository-only.** These files document the contracts for contributors
  and reviewers. They are never installed into the profile and never appear
  in an owner's environment.
- **The templates are the source of truth.** If an example ever disagrees
  with `templates/task-brief.md`, `templates/handoff-result.md`, or
  `templates/approval-request.md`, the template wins; fix the example.

Files:

- `kanban-task.md` — a complete incoming task brief from a Chief of Staff
- `kanban-result.md` — the matching completed result handoff
- `direct-chat.md` — an annotated first conversation with an owner
- `deliverable-email-sequence.md` — the finished deliverable the task above produced
